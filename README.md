Data 3463 Project Proposal: Skills in Data Job Postings
Group: Ken Reyes and David Akanle


Focal Question
Which technical skills are most frequently required in data analyst, data scientist, and data engineer job postings in major cities in Canada, and how do these requirements differ between roles?

Why it matters
Students trying to break into data careers often don’t know which skills to prioritize for the role they are trying to achieve. Comparing real data from job postings across these three roles will show which skills matter most for each one.

Planned dataset
The final dataset we have planned will have one row per job posting with columns that include roles (analyst, scientist, or engineer), posting details (employer, location, salary, etc.), and skills (python, sql, excel, tableau, ml, etc.) which will be a 0/1 column.
